# 🌿 MATRIVA — ગુજરાતી પરિચય

**ગર્ભાવસ્થા વિશેના પ્રશ્નો, અઠવાડિયાની યોજના અને વ્યક્તિગત નોંધો — એક જ કાર્યસ્થળમાં.**

> [!IMPORTANT]
> MATRIVA વિકાસ અને પ્રદર્શન માટેનો પ્રોજેક્ટ છે. સંભાળના નિયમો અને સુરક્ષા સામગ્રીની તબીબી સમીક્ષા હજી બાકી છે. હિન્દી અને ગુજરાતી સુરક્ષા સંદેશાઓની માતૃભાષી સમીક્ષક દ્વારા તપાસ પણ જરૂરી છે. તે નિદાન કરતું નથી, દવા સૂચવતું નથી અને ડૉક્ટરનું સ્થાન લેતું નથી. [સમીક્ષાની જરૂરિયાતો](../clinical-review.md) વાંચો.

## 💚 MATRIVA શું છે?

MATRIVA ગર્ભાવસ્થા વિશેની માહિતી, મુલાકાતની યોજના અને રોજિંદી નોંધોને એક ચેટ કાર્યસ્થળમાં લાવે છે. માતા અને તેમની સંભાળમાં મદદ કરતા લોકો પ્રોજેક્ટને સમજવા અને અજમાવવા તેનો ઉપયોગ કરી શકે છે.

ડિફૉલ્ટ માહિતી શોધવાનું એન્જિન સ્થાનિક રીતે ચાલે છે અને તેને AI સેવાની API keyની જરૂર નથી. સામાન્ય પ્રશ્ન માટે તે ઉપલબ્ધ પાત્ર સ્રોતોમાંથી માહિતી શોધે છે, સ્રોત દર્શાવે છે અથવા પૂરતી માહિતી ન હોવાનું સ્પષ્ટ કહે છે. કટોકટી અને પ્રતિબંધિત વિનંતીઓ માટે સામાન્ય શોધ પહેલાં નક્કી કરેલી સુરક્ષા પ્રક્રિયા ચાલે છે.

## 🚀 તમારા કમ્પ્યુટર પર ચલાવો

Python **3.11 અથવા 3.14**, Node.js **24** અને npm જરૂરી છે. પ્રથમ સેટઅપ માટે:

```bash
git clone https://github.com/neevmodh/MATRIVA.git
cd MATRIVA/backend
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
```

`python -c "import secrets; print(secrets.token_urlsafe(48))"`થી નવો secret બનાવો અને `backend/.env`માં `JWT_SECRET` તરીકે સેટ કરો. `RAG_ENGINE=local` રાખો. પછી:

```bash
alembic upgrade head
uvicorn app.main:app --reload --host 127.0.0.1 --port 8010
```

બીજા ટર્મિનલમાં પ્રોજેક્ટની મુખ્ય ડિરેક્ટરીમાંથી:

```bash
cd frontend
npm ci
printf 'NEXT_PUBLIC_API_URL=http://localhost:8010\n' > .env.local
npm run dev
```

**http://localhost:3000** ખોલો. નવું ખાતું બનાવો અને સંમતિ આપીને પ્રોફાઇલ સેટ કરો. `/plan`, `/readings` અથવા `/foods` અજમાવો. `.env` અને `.env.local` બનાવવાના પગલાં માત્ર પ્રથમ સેટઅપ માટે છે; જૂની ખાનગી સેટિંગ્સ બદલતાં પહેલાં તપાસો.

નવા ડેટાબેઝમાં ચેટ માટે મંજૂર થયેલા સ્રોતો હોતા નથી. તેથી સામાન્ય પ્રશ્ન પર પૂરતા સ્રોતો ન મળવાનો જવાબ યોગ્ય વર્તન છે. [સ્રોત ઉમેરવાની અને સમીક્ષાની પ્રક્રિયા](../deployment.md#what-the-image-does-not-contain) જુઓ. અપલોડ કરેલા દસ્તાવેજો પહેલાં pending રહે છે.

## 🔐 ડેટા અને સંમતિ

આરોગ્યની પ્રોફાઇલ અને સંભાળની નોંધો લખવા માટે સંમતિ જરૂરી છે. સંમતિ પાછી ખેંચવાથી અથવા આરોગ્યની પ્રોફાઇલ કાઢવાથી પ્રોફાઇલ અને સંભાળની નોંધો દૂર થાય છે, પરંતુ ચેટનો ઇતિહાસ રહે છે. ખાતું કાઢવાનો વ્યાપ વધારે છે: ખાતું અને તેની સાથે જોડાયેલી વ્યક્તિગત નોંધો દૂર થાય છે. JSON exportથી પોતાનો ડેટા ડાઉનલોડ કરી શકાય છે. [ગોપનીયતાની સંપૂર્ણ માહિતી](../privacy.md) વાંચો.

## 🎨 ટેકનોલોજી અને ગુણવત્તા

પ્રોજેક્ટમાં Python, TypeScript, JavaScript, CSS, Shell, Dockerfile, Mako અને Mermaidનો ઉપયોગ થાય છે. મુખ્ય ટેકનોલોજી Next.js, React, FastAPI, SQLAlchemy, PostgreSQL/pgvector અને Redis છે.

GitHub Actionsમાં સાત જરૂરી CI jobs છે; CodeQL અલગથી ચાલે છે. પરીક્ષણો સોફ્ટવેરનું વર્તન તપાસે છે, તબીબી સામગ્રી સાચી છે એવું પ્રમાણિત કરતા નથી. [પરીક્ષણની વિગતો](../testing.md) જુઓ.
