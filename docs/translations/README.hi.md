## 💚 MATRIVA क्या है?

MATRIVA गर्भावस्था से जुड़ी जानकारी, मुलाकात की योजना और रोजमर्रा के रिकॉर्ड को एक चैट कार्यक्षेत्र में लाता है। इसका उपयोग मां और उनकी देखभाल में सहयोग करने वाले लोग प्रोजेक्ट को समझने और आजमाने के लिए कर सकते हैं।

डिफॉल्ट जानकारी खोजने वाला इंजन स्थानीय रूप से चलता है और उसे किसी AI सेवा की API key नहीं चाहिए। सामान्य सवालों के लिए यह उपलब्ध पात्र स्रोतों से जानकारी खोजता है, स्रोत बताता है या पर्याप्त जानकारी न होने की बात स्पष्ट करता है। आपात स्थिति और प्रतिबंधित अनुरोधों के लिए सामान्य खोज से पहले तय सुरक्षा प्रक्रिया चलती है।

## 🧭 क्या कर सकते हैं?

| सुविधा | कमांड या स्थान | उद्देश्य |
|---|---|---|
| साप्ताहिक योजना | `/plan`, `/week`, `/visits` | गर्भावस्था का सप्ताह, मुलाकात की योजना और कार्य देखें |
| रोज की जानकारी | `/checkin`, `/check`, `/log` | चेक-इन और स्क्रीनिंग का कार्यप्रवाह आजमाएं |
| स्वास्थ्य रिकॉर्ड | `/readings` | माप दर्ज करें, रुझान देखें और रिपोर्ट आयात करें |
| भोजन रिकॉर्ड | `/meals`, `/foods` | भोजन दर्ज करें और अनुमानित पोषण जानकारी देखें |
| डॉक्टर के लिए सारांश | `/summary` | दर्ज जानकारी से प्रिंट करने योग्य सारांश तैयार करें |
| स्रोतों को समझें | `/evidence`, `/library`, `/book`, `/map` | स्रोत और प्रमाण के लेबल देखें |
| अपने डेटा पर नियंत्रण | Settings | सहमति, डेटा निर्यात और खाता हटाने के विकल्प देखें |

पोषण की गणनाएं अनुमान हैं। देखभाल के नियमों की चिकित्सकीय समीक्षा बाकी है। वर्तमान रिमाइंडर ऐप खुले होने पर दिखाई देते हैं; push या SMS सुविधा अभी नहीं है।

ऐप में भाषा चुनने के तीन विकल्प हैं: English, हिन्दी और ગુજરાતી। Hinglish इनपुट की शैली है। यह हिन्दी दस्तावेज प्रोजेक्ट का परिचय और सेटअप बताता है; इससे ऐप के सभी जवाब हिन्दी में नहीं हो जाते। [भाषा से जुड़े सवाल](../faq.md) देखें।

## 🚀 अपने कंप्यूटर पर चलाएं

Python **3.11 या 3.14**, Node.js **24** और npm चाहिए। नए सेटअप के लिए:

```bash
git clone https://github.com/neevmodh/MATRIVA.git
cd MATRIVA/backend
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
```

`python -c "import secrets; print(secrets.token_urlsafe(48))"` से नया secret बनाएं और `backend/.env` में `JWT_SECRET` के रूप में सेट करें। `RAG_ENGINE=local` रखें। फिर:

```bash
alembic upgrade head
uvicorn app.main:app --reload --host 127.0.0.1 --port 8010
```

दूसरे टर्मिनल में प्रोजेक्ट की मुख्य डायरेक्टरी से:

```bash
cd frontend
npm ci
printf 'NEXT_PUBLIC_API_URL=http://localhost:8010\n' > .env.local
npm run dev
```

**http://localhost:3000** खोलें। नया खाता बनाएं और सहमति देकर प्रोफाइल सेट करें। `/plan`, `/readings` या `/foods` आजमाएं। `.env` और `.env.local` कॉपी करने वाले कदम केवल पहले सेटअप के लिए हैं; मौजूदा निजी सेटिंग्स को बदलने से पहले उन्हें देखें।

नए डेटाबेस में चैट के लिए अनुमोदित स्रोत नहीं होते। इसलिए सामान्य सवाल पर पर्याप्त स्रोत न मिलने का जवाब आना सही व्यवहार है। [स्रोत जोड़ने और समीक्षा की प्रक्रिया](../deployment.md#what-the-image-does-not-contain) देखें। अपलोड किए गए दस्तावेज पहले pending रहते हैं।

## 🔐 डेटा और सहमति

स्वास्थ्य प्रोफाइल और देखभाल के रिकॉर्ड लिखने के लिए सहमति जरूरी है। सहमति वापस लेने या स्वास्थ्य प्रोफाइल हटाने से प्रोफाइल और देखभाल के रिकॉर्ड हटते हैं, लेकिन चैट इतिहास रहता है। खाता हटाने का दायरा बड़ा है: खाता और उससे जुड़े व्यक्तिगत रिकॉर्ड हटते हैं। JSON export से अपना डेटा डाउनलोड कर सकते हैं। [पूरी गोपनीयता जानकारी](../privacy.md) पढ़ें।

## 🎨 तकनीक और गुणवत्ता

प्रोजेक्ट में Python, TypeScript, JavaScript, CSS, Shell, Dockerfile, Mako और Mermaid का उपयोग है। मुख्य तकनीकें Next.js, React, FastAPI, SQLAlchemy, PostgreSQL/pgvector और Redis हैं।

GitHub Actions में सात आवश्यक CI jobs हैं; CodeQL अलग से चलता है। परीक्षण सॉफ्टवेयर के व्यवहार को जांचते हैं, चिकित्सकीय सामग्री की सत्यता प्रमाणित नहीं करते। [परीक्षण का विवरण](../testing.md) देखें।
